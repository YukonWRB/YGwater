How formats and mappings fit together

A source groups data from the same provider or system. A workbook format belongs to that source and describes how to read a particular worksheet. The mappings describe what the incoming values mean in AquaCache.

ConceptQuestion it answersExample
SourceWhich provider or system supplies these data?ALS laboratory exports.
Workbook formatWhere are the samples, dates, parameter labels, units and results?The Samples worksheet has sample columns; the Detailed Report worksheet has one result per row.
Parameter mappingWhich AquaCache parameter and analytical qualifiers describe this source result?The source code pH-L with pH units maps to AquaCache pH, with a laboratory result type and liquid matrix.
Location mappingWhich existing AquaCache location represents this source location label?A provider's station code maps to the corresponding monitoring location. Confirm the geographic identity before using a mapping.
Result-flag mappingHow should a source qualifier affect a result?Assign a result condition or deliberately exclude results carrying a particular flag.
Mapping revisionWhich saved collection of mappings is currently in use?Published version 2 stays in use while edits wait in draft version 3.

Sharing a mapping between workbook and package imports

Save a mapping for all formats for this source when the same incoming labels mean the same thing in each format. Those source-wide mappings can also be used by AquaCache package imports configured for that source. A format-specific mapping overrides the shared mapping for that workbook format. Creating another format does not require duplicating its source's shared mappings.

For example, two ALS workbooks can both supply pH-L and pH units and reuse one shared mapping, even when their cells are arranged differently. A report that supplies the name Conductivity instead of the corresponding code can have its own format-specific mapping. The parser handles the different arrangement; the mapping handles the different label.

Matching several source columns

A source parameter need not be identified by just its name and unit. Choose Several source columns to combine name, unit, speciation, sample fraction, result type, or other source fields. Every listed condition must match. This keeps two otherwise identical source rows distinct when their chemical form or fraction differs.

In the workbook format, retain these fields under Additional columns used for matching. Then add their source names and expected values to the parameter mapping. For example, an XLR mapping can require Analyte = Conductivity, Units = µS/cm, and Matrix = Water together. A transfer from another AquaCache instance can retain its separate chemistry columns in the same way.

The source conditions identify the incoming row. The destination fields independently specify the AquaCache parameter, matrix, fraction, reporting basis, chemical form and result type. Review both sides; an incoming fraction label does not automatically assign the destination fraction. An explicitly empty unit condition matches missing source units. Omit the unit condition when the mapping should not constrain units, and ensure any required conversion is still defined correctly.

Editing and publishing

  1. Select the source and, when appropriate, the workbook format. Review a saved mapping before editing it.
  2. Save the mapping as a draft. The current published revision continues to control imports.
  3. Review and publish the selected scope. Publication activates that scope's parameter, location and result-flag mappings together.
  4. Parse an already-open workbook again to use the new revision. Its preview reports results that remain unmapped or excluded.

The previous published revision becomes retired history. Open it to see what earlier imports used, then choose Open current version to make a new change. Earlier uploads retain their recorded mapping revision. Workbook layout settings themselves save immediately; the draft/published/retired lifecycle applies to mapping revisions.
