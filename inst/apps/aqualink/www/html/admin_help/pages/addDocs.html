Documents

Use this page to upload and manage documents linked to AquaCache records.

Link spatial features

Choose a spatial feature layer and click Find spatial features. To browse further through a large layer, enter a full or partial feature name in Browse features starting at name. Each search lists up to 100 features in name order, starting at the entered name. Select the features to associate with the document. Features already selected remain available across searches and layers; remove a selected feature to unlink it.

Before saving

Check document type, title, date, linked records, visibility, and file naming.
