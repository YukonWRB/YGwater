Add discrete data

Use this page to add discrete sample results to AquaCache. The workflow creates sample records in discrete.samples and result records in discrete.results from either uploaded files or manually entered rows.

Location and sub-location

Select the location before uploading or entering results. Select the sub-location when results belong to a specific point within the location. If the needed location or sub-location does not exist, the page can send you to the relevant location tool to create it first.

Input methods

Use file upload when you have a spreadsheet or tabular export. Choose a workbook format and Parse file, then review the separate Map parameters, locations and result flags accordion if mappings need attention. The Samples table is always visible, including when empty. Use manual entry for a small number of results. File and manual entry can be combined: after parsing a file, add field results to an uploaded sample or use New sample to create another sample in the same preview.

Samples and samplers

Select a row in the Samples table to review its results. Open Edit sample details below the table to edit that sample, or choose New sample directly below the Samples table to clear its selection and open a blank sample form. Select one or more people in Sampler(s), then create or update the sample to stage those assignments. Use Create new observer to add a person to the shared observer list; enter their first name, last name, and organization.

Create or edit results

The New sample and New result buttons sit directly below their tables, outside the Edit sample details and Edit result details accordions. A blank editor displays a creating-new-record message and a Create new sample or Create new result button. Selecting a row changes the message to editing and the button to Save sample changes or Save result changes.

The results table appears below the sample editor. Select a result row, then open Edit result details below the results table. The form loads that result's parameter, value or condition, analytical details, laboratory identifiers, analysis datetime, grade, approval and note. Values use the displayed target unit, including when the source file used another unit. Choose Save result changes to update the selected row in the preview. Original file values remain visible for comparison.

Blue cells show source values; green cells show values to save in AquaCache. The results table shows one parameter column and keeps the original result, unit and flag for comparison. An unresolved parameter is labelled Unmapped and shown in blue until assigned. Sample metadata is reviewed in the Samples table; analysis datetime and lab report/sample identifiers remain available in the result editor.

Choose New result directly below the results table to clear its selection and open a blank result form for the selected sample. Select the result type, matrix state and value type before saving. Both New buttons also discard unsaved form entries when clicked again. After adding a result, the form switches to editing that row; choose New result again to add another. Unmapped file results are also shown and can be assigned a parameter individually; use the mapping accordion when the assignment should apply to future files. Switching samples or reparsing clears the result selection. All sample and result edits stay in the preview until Upload to AquaCache; use Edit samples and results to modify records already stored in the database.

Workbook formats and mappings

The mapping accordion contains separate Parameters, Locations, and Result flags accordions. After a successful parse or mapping refresh, each section opens only if it has unresolved mappings, and the parent opens if any section needs attention. When everything is mapped, the parent remains collapsed and available for review. The controls are hidden when there are no source values to map. Locationless field and trip blanks do not require location mappings. You can still open or close each accordion manually.

Each section initially shows only unresolved values. Use its Show already mapped checkbox to review existing parameter, location, or flag mappings. Selecting a result flag loads its saved handling from the same configuration snapshot used to prepare the preview.

A workbook format tells the parser where to find sample details, analyte labels, units, and results. In Discrete data → Manage import setups, create or edit a format, choose an example workbook, inspect its worksheet, and preview parsed rows before saving. Layout settings save immediately and affect future file previews. The wide-table option reads one sample per row with analytes in separate columns; an optional group heading row preserves repeated analyte names such as dissolved and total metals.

Parameter mappings translate the source analyte code/name and unit into an AquaCache parameter and its analytical details. Location mappings translate source station names/codes into AquaCache locations. Shared source mappings can be reused by several workbook formats; mappings for one format override the shared ones for that format.

Mapping changes save immediately. Preview an open workbook again after changing its layout or mappings.

In the parameter mapping editor, Applies to defaults to Source-wide / package downloads. Select This workbook format for a format-specific override. Existing format-specific mappings still take precedence over a source-wide mapping; review or remove those overrides in Import setup when needed.

Both the upload mapping editor and Import setup suggest the conversion multiplier and offset from public.unit_conversions when a known source-to-target unit pair is selected. Target units depend on the parameter and matrix state. Saved custom conversions remain intact when opened, and suggested values can be edited before saving. Blank, unknown, or ambiguous unit pairs receive no suggestion; review the multiplier and offset manually in those cases. Conversions are applied as source value × multiplier + offset, including result-condition thresholds.

Project-specific location mappings

Use Project for location mappings immediately above the source-location table to distinguish repeated laboratory station names such as SW01 or MW-01. A mapping can apply to a particular project or be a project-free fallback. Within the selected project, project-specific mappings take precedence over project-free fallbacks, and format-specific mappings override source-wide mappings within the same project scope.

With no project selected, saved mappings resolve automatically only when their effective targets agree, including sub-location. Conflicting targets stay unresolved and appear in Candidates; choose a project or explicitly map the source name. Automatic name/code/alias matching is restricted to locations belonging to a selected project. Changing the project refreshes the preview and is recorded with the upload configuration.

Create missing locations

The Create missing locations tab lists unresolved source names. Complete each location's required name, type, latitude and longitude, then choose Create locations. Each row has a Create mapping checkbox, checked by default. Clear it to create the location without saving a source-name mapping. Saved mappings use the current workbook format and mapping project. The mapping project is also preselected in the new location's project memberships; those memberships can be edited independently.

After creation, completed rows and the coordinate picker reset. The source-location table and the Location choices in sample details refresh with the new locations. A location created without a mapping remains available for manual selection. If the workbook, format or project changes while creation is running, preview the current workbook again before continuing.

Before upload, confirm sample fraction, reporting basis, chemical form, analytical target, and endpoint whenever the chosen parameter requires them. Check the omission summary when only some source analytes are mapped.

Parameters, units, and values

Check parameter names and units before upload. A result should only be saved when the parameter is identified and the value is valid. Avoid uploading ambiguous columns until the mapping is corrected.

Documents

Attach supporting documents when they should be linked with the uploaded samples, such as lab reports, field sheets, or chain-of-custody documents.

Before uploading

Mappings can match several source columns. When name and unit do not uniquely identify an analyte, retain the relevant columns in the workbook format under Additional columns used for matching. In Manage import setups choose Several source columns, then add one condition for each source value, such as name, unit, sample fraction, chemical form, and result type. Every condition must match. Source conditions and assigned AquaCache metadata are independent: source IDs and names from another AquaCache instance must be mapped to the destination catalogue. Missing matching columns leave results unmapped; they are never silently ignored. Published source mappings are shared by workbook formats and package adapters that provide those source fields.

Review the preview table carefully. Confirm sample dates, location, sub-location, parameter matches, units, values, and attached documents. Upload only after the preview reflects the records that should be added to AquaCache. Use Upload only the selected sample for a deliberate sample subset; the partial-upload confirmation and import history record the omitted results.
