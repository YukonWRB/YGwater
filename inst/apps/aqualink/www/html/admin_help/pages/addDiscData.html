Add discrete data

Use this page to add discrete sample results to AquaCache. The workflow creates sample records in discrete.samples and result records in discrete.results from either uploaded files or manually entered rows.

Location and sub-location

Select the location before uploading or entering results. Select the sub-location when results belong to a specific point within the location. If the needed location or sub-location does not exist, the page can send you to the relevant location tool to create it first.

Input methods

Use file upload when you have a spreadsheet or tabular export. Use manual entry for a small number of results. Uploaded files can be mapped from wide or long formats, depending on how parameters, units, dates, and values are arranged. After previewing a file, select New sample in Sample details to add another sample and then add its results in the result form.

Samples and samplers

Select a sample in Sample details to edit it, or use New sample to add a sample to the current preview. Select one or more people in Sampler(s), then create or update the sample to stage those assignments. Use Create new observer to add a person to the shared observer list; enter their first name, last name, and organization.

Workbook layout examples

Choose a layout by looking at how the worksheet stores results. These spreadsheet-style examples show the shapes expected by each parser. The examples are illustrative; your column or row labels can differ and are configured in the workbook format.

Long table: one result per row

Each row contains one analyte result. Sample details repeat on every result row for that sample. Choose this when the workbook has columns for station, date, sample ID, parameter, unit, and result.

Quick choice

  • Use Long table when each worksheet row is one result.
  • Use Transposed table when each sample is a column and each analyte is a row.
  • Use XLR Detailed Report for the lab's Detailed Report export with its standard report header.

Mappings

Mappings tell the app where to find parameters, units, dates, values, and samples in the uploaded file. Save reusable mappings for common lab exports or repeated field templates. Before saving a mapping, verify that parameter columns resolve to the intended AquaCache parameters. Sample fraction and result speciation must be selected whenever the chosen parameter requires them.

Parameters, units, and values

Check parameter names and units before upload. A result should only be saved when the parameter is identified and the value is valid. Avoid uploading ambiguous columns until the mapping is corrected.

Documents

Attach supporting documents when they should be linked with the uploaded samples, such as lab reports, field sheets, or chain-of-custody documents.

Before uploading

Review the preview table carefully. Confirm sample dates, location, sub-location, parameter matches, units, values, and attached documents. Upload only after the preview reflects the records that should be added to AquaCache.
