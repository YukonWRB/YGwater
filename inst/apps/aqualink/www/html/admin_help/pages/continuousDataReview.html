Review and edit timeseries data

Use this page to inspect a continuous timeseries and add or update its grades, approvals, qualifiers, and corrections.

Choose a timeseries and view its data

  1. Select a row in Timeseries selection.
  2. Open Review data and choose a date range to see the plot. The plot starts at the latest year available for that timeseries.
  3. Use the plot toolbar to zoom or pan. Choose Show latest year or Show full timeseries to change the plot view. These buttons do not set review dates or dates saved with a record.

Review dates and record dates have different jobs. The optional review start and end dates filter the list of records that overlap a period and shade that period on the plot. They do not set dates on a grade, approval, qualifier, or correction.

Find records for a period

Enter both review dates to list grades, approvals, qualifiers, and corrections that overlap that interval. You can enter the dates directly, pick them from the plot, drag across the plot to choose both, or use the snap table to line them up with an existing record, field visit, or instrument event. Choose Clear review range to remove the filter; the plot returns to the latest year.

Times are shown in the selected input timezone. The database stores datetimes in UTC.

Add or edit a record

  1. In Manage grades, approvals, qualifiers, and corrections, choose the record type.
  2. To edit an existing record, select its row in the table for the current type. Its saved values and start/end datetimes appear in the form.
  3. Change only the fields you want to change. Leave the record start and end datetimes as shown when the time interval should stay the same.
  4. To add a new record, enter its start and end datetimes in Dates saved with this record. You can copy a valid review range into these fields, then adjust either date before saving.
  5. Choose Add or Update to save. The button label shows which action will occur. Use Clear selected record to leave edit mode.
  6. After a successful save, the form returns to add mode. To edit that record again, select its row from the records table.

What happens when records overlap

  • Grades and approvals may replace overlapping records or adjust their date bounds. Review the listed records in the confirmation before applying the change.
  • Qualifiers may overlap; adding one does not remove another qualifier.
  • Corrections can stack. Each correction type has a priority, and corrections are applied in priority order. The confirmation lists existing corrections over the same dates and shows the selected type's priority.

Correction fields

Choose a correction type to see its required fields. Labels describe the expected value, such as an offset, scaling percentage, time window, or equation. When editing, the form is filled with the saved correction values. Check the dates, type, values, and priority before applying the update.
