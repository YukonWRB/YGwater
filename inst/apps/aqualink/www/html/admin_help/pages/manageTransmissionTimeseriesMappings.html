Transmission timeseries mappings

Use this page to map fields in a provider payload to basic AquaCache continuous timeseries. One transmission route can populate many timeseries, and routes sharing a platform identifier can reuse the same downloaded payload.

Required relationships

The selected timeseries must belong to the same location as the logger deployment behind the transmission route. The database enforces this rule and also rejects compound timeseries.

Field names and transformations

Source field must match the parser output exactly, including prefixes and underscores used by multi-location payloads. Apply a multiplier and offset only when the transmitted values need a deterministic numeric conversion. Enter source missing-value sentinels as a JSON array, for example ["99999","-9999"].

Mapping config is a JSON object reserved for provider-specific extraction, unit, quality-code, or future transformation settings. Disable a mapping when it should be retained for history but no longer imported.

NESDIS source workflow

For direct GOES/NESDIS retrieval, set the target basic timeseries source_fx to downloadNESDIS. The importer obtains the route, platform identifier, parser format, and field mapping from database metadata; these values do not need to be repeated in each timeseries' source_fx_args.
