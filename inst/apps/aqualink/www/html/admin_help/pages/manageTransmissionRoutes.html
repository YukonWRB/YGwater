Transmission routes

Routes describe the schedule, endpoint, message format, and adapter configuration used to retrieve a transmission. A setup identifies the deployed logger and provider-facing platform; one setup can have multiple routes.

Direct GOES/NESDIS retrieval

Use message format SHEF for standard payloads or SHEF_McMaster for the McMaster multi-location convention. Route config is a JSON object and can contain settings such as max_days, overlap_minutes, lrgs_servers, lrgs_port, and timeout_seconds.

After saving a route, create its provider-field links under Timeseries mappings. Review retrieval outcomes under Import history.
