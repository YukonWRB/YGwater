Transmission import history

This read-only page shows the most recent 1,000 transmission retrieval runs across providers and importers. Use the table filters to isolate a route, status, source server, or time window.

Interpreting a run

query_since and query_until describe the provider query window. The received, parsed, and inserted counts distinguish retrieval problems from parsing, mapping, or duplicate-data outcomes. A successful or no-data run can advance the durable route cursor.

For failed runs, inspect the error message and source metadata before retrying. Import history is written by the importer and cannot be edited from YGwater.
